# الوجبات والتمارين

تطبيق شخصي لمستخدم واحد: تتبّع الماكروز والخطة الأسبوعية للوجبات، وتسجيل جلسات
التمرين. عربي بالكامل، RTL، ويعمل بدون إنترنت — كل البيانات على الجهاز في SQLite.

المبدأ الحاكم: **الخطة هي السجل**. كل وجبة مخطّطة وكل مجموعة تمرين تبدأ بحالة
«كما هو مخطّط»، وتؤكّدها بضغطة واحدة، وتعدّل فقط حين يختلف الواقع.

## التشغيل

```bash
npm install
npx expo start
```

ثم افتح المشروع من تطبيق **Expo Go** على جوالك.

أول تشغيل يفعل ثلاثة أشياء تلقائياً: يفرض اتجاه RTL ثم يعيد تحميل نفسه مرة واحدة
(الاتجاه لا ينطبق إلا بعد إعادة تحميل)، ويكتب الخطة الغذائية وبرنامج التمارين في
قاعدة بيانات فارغة.

**خطوة واحدة يدوية:** برنامجك لا يحدّد أي أيام الأسبوع هي أيام التمرين، فجدول
الأسبوع يُترك فارغاً عمداً. افتح «الإعدادات ← محرّر البرنامج ← جدول الأسبوع»
واختر أيامك الخمسة.

## الفحوص

```bash
npm run verify   # typecheck + lint + الاختبارات + فحص قاعدة البيانات
```

مفردة:

| الأمر | ماذا يفعل |
|---|---|
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint عبر `expo lint` |
| `npm test` | اختبارات المنطق الصِّرف عبر مشغّل Node المدمج (بدون مكتبة اختبار) |
| `npm run db:check` | يطبّق الـ migration على SQLite حقيقية ويتحقق من القيود والعلاقات |
| `npm run seed:check` | يكتب الخطة المزروعة في SQLite حقيقية ويتحقق من مجاميعها |
| `npm run db:generate` | يولّد migration بعد تعديل `src/db/schema.ts` |
| `npm run plan:totals` | يطبع ماكروز كل يوم من أيام الخطة المزروعة |

## البنية

```
app/                    مسارات Expo Router (الشاشات)
src/db/                 مخطط Drizzle، العميل، النسخ الاحتياطي، بيانات الخطة
src/queries/            قراءة وكتابة قاعدة البيانات، مقسّمة حسب المجال
src/lib/                منطق صِرف: الماكروز، الالتزام، التقدّم، التواريخ
src/components/         مكوّنات الواجهة المشتركة
src/theme/              الألوان، الخطوط، المسافات، وإعدادات الحركة
supabase/functions/     دوال Edge (Deno) — المرحلة ٥
docs/ideas.md           أفكار مؤجَّلة خارج المراحل الحالية
```

قاعدة البيانات هي مصدر الحقيقة. `useDbQuery` يعيد تشغيل القراءة بعد أي كتابة،
فلا يوجد تخزين مؤقت يحتاج إبطالاً. Zustand مخصص لحالة الواجهة فقط (مؤقّت الراحة).

## الحركة

`src/theme/motion.ts` يترجم `.claude/skills/apple-design` إلى Reanimated:
النوابض مثبّطة تثبيطاً حرجاً افتراضياً، والارتداد محجوز لما بعد السحب أو القذف
فقط. التغذية الراجعة عند الضغط لا عند الإفلات (`PressableScale`). كل شيء يحترم
إعداد تقليل الحركة في النظام.

## Supabase (المرحلة ٥ — اختيارية)

التطبيق كامل بدونها. تفعّلها لأمرين: نسخة احتياطية سحابية، وتقدير ماكروز طعام من
وصف عربي.

1. أنشئ مشروع Supabase و bucket باسم `backups`.
2. أضف في `app.json` تحت `expo.extra`:
   ```json
   { "supabaseUrl": "https://xxxx.supabase.co", "supabaseAnonKey": "eyJ..." }
   ```
3. انشر الدالة:
   ```bash
   supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
   supabase functions deploy estimate-food
   ```

**مفتاح Anthropic لا يدخل التطبيق إطلاقاً.** التطبيق يحمل رابط المشروع ومفتاح
`anon` فقط، وكلاهما عام بطبيعته؛ المفتاح السرّي يبقى في Supabase وحدها وتقرأه
دالة الـ Edge.

## البيانات

الخطة الغذائية المزروعة حقيقية: الكميات وتركيب الوجبات منقولة كما هي من خطة
المستخدم. أرقام الماكروز لكل حصة قيم مرجعية معتادة — الخطة تذكر مجاميع اليوم لا
تفاصيل كل صنف — وقابلة للتعديل من داخل التطبيق.

برنامج التمارين مزروع كذلك: خمسة أيام، ٣ مجموعات × ١٠ تكرارات، راحة دقيقتان،
منقولة حرفياً. أسماء التمارين بالإنجليزية كما وردت في البرنامج (وكما هي على
أجهزة النادي)، والعضلة المستهدفة بالعربية تحتها. شيئان لم يحدّدهما البرنامج:
أيام الأسبوع (تُختار من محرّر البرنامج)، ووحدة البلانك — سُجّل ٦٠ ثانية لأن ٦٠
تكرار بلانك غير وارد، وتغييرها تعديل واحد.
